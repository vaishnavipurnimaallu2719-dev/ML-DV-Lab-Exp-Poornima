# Data Visualization Lab – Power BI starter pack

This folder contains datasets and step-by-step instructions for 8 introductory Power BI experiments.

## Important
These are **starter materials**, not completed `.pbix` files. Open Power BI Desktop, import the CSV in each experiment folder, follow `Instructions.txt`, and save the report using the suggested `.pbix` filename.

## Experiments
1. Line Chart
2. Bar Chart
3. Pie Chart
4. Donut Chart
5. Table and Matrix
6. Slicers and Filters
7. Cards and KPI
8. Interactive Dashboard

## How to use
1. Extract this ZIP.
2. Open Power BI Desktop.
3. For each experiment, choose Home → Get data → Text/CSV.
4. Select the CSV from that experiment's folder.
5. Follow its Instructions.txt.
6. Save the report as a `.pbix` file in the same experiment folder.

After completing the reports, upload the entire `DV_Lab_Experiments` folder contents to the `DV` folder in your GitHub repository.
